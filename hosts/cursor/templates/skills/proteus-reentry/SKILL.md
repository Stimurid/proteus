# Reentry

Read in order: `state/IDENTITY.md`, `state/CURRENT.md`, `state/FRONTIER.md`, `state/DECISIONS.md`, `state/UNRESOLVED.md`, latest `evidence/runs/*/RUN_RECEIPT.md` if present.

Output a short mount receipt: project, RUN_ID, frontier, one unresolved, next action. Do not ask the user to paste prior chat.
