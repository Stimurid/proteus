# Proteus

Portable cognitive infrastructure for a coding agent. First host: Cursor.

This repository is the **executable ideal body**. Cursor incarnation is generated by:

```
python -m proteus.install_cursor --run-id <RUN_ID> --backup-dir <backup-dir>
```

(`PYTHONPATH=src` if the package is not installed.) Do not treat `.cursor/` as the source of truth. Change `src/proteus/` and `hosts/cursor/templates/`, then reinstall.

Portable handoff (single zip for a fresh machine/workspace):

```
python -m proteus.handoff pack
```

Artifact: `distribution/proteus-portable-handoff.zip`. Usage is inside the zip (`proteus-handoff/READ_ME_FIRST.md`). Destination reconstruct: `proteus-handoff\bootstrap.cmd`.

Blind-start packet (read-only carrier): `_BOOTSTRAP/BLIND_START/`.
Canonical live status: `state/CURRENT.md` / `state/FRONTIER.md`. Root `CURRENT.md` / `FRONTIER.md` / `DECISIONS.md` / `UNKNOWN.md` are superseded residue.

Project mount (activate Proteus on an existing Cursor coding-agent project):

```
python -m proteus.activate --project <path-to-existing-project>
python -m proteus.activate --project <path> --dry-run
python -m proteus.activate --project <path> --remove
```

(`PYTHONPATH=src` if needed.) Writes Proteus-owned surfaces and `.proteus/ENTRY.md`; does not overwrite an existing `AGENTS.md` or non-`proteus-*` Cursor rules. Not Gate 1.

Project capsule (compact, practical context for a fresh coding agent):

```
python -m proteus capsule --project C:\path\to\project --out C:\handoff\PROJECT_CAPSULE.md
```

The command is read-only with respect to the selected project. It records observed Git state, manifests, mandatory instructions, and bounded excerpts from standard overview/current-state/roadmap documents. Give the Markdown file to the fresh agent as project context, then have it inspect the cited sources before editing. It deliberately omits diff bodies, untracked file contents, binaries, dependency trees, environment files, and agent transcripts; credential-shaped strings in included excerpts are heuristically redacted. Use `--max-chars` (default 48,000; minimum 4,000) to bound the result.
