### 1.2 Sync script

- `C:\projects\Proteus\scripts\aiye-world-sync.ps1`
  - `git fetch origin` → `git merge --no-ff origin/main`.
  - Union merge handled transparently for `claims.jsonl` (via `.gitattributes`).
  - Non-claims merge conflicts → `git merge --abort`, exit 2 for operator.
  - For every entity whose files changed in the merge, runs `proteus world reconcile --entity-id <id>`
    so same-topic divergent claims land as `conflicts_with` chains with `status=conflict` via the
    existing `store.write_claim` logic — never silent duplicates.
  - `proteus world rebuild-index` (host-local VIEW).
  - Commits any status rewrites + pushes `host/aorus` and (fast-forward) `main`.
  - Logs to `~/.aiye/world/.sync.log` (gitignored).
