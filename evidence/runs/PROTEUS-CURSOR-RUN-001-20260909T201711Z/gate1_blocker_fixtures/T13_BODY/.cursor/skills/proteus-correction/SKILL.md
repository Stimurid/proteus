# Correction capture

Write `state/corrections/<timestamp>.md` with: quote/summary, provenance (this conversation), proposed scope (episode|project|global), whether it repeats a prior correction, and status CAPTURED_NOT_PROMOTED.

Do not turn a single episode into a global rule.
