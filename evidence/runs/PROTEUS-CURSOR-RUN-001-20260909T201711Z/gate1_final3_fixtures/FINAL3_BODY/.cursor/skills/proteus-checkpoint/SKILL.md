# Checkpoint

Update `state/CURRENT.md` and `state/FRONTIER.md`. Append to `state/DECISIONS.md` only for actual decisions with provenance.

Write `evidence/runs/<RUN_ID>/CHECKPOINT.md` with: done, changed, decisions, unresolved, next frontier, git dirty state, test state.

Do not require the user to file this by hand.
